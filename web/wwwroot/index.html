What is this?

An editor for ghūl, a statically typed language that targets .NET. Type on the left; press Ctrl+Enter or the run button to compile and run.

While you type

A real ghūl compiler is analysing what you write, so the errors, hovers, completions and inlay hints are the same ones you would get in an editor rather than an approximation of them. The dot in the top right says whether that analyser is connected.

When you run

Your code is compiled on the server, and the assembly it produces is sent back and executed in this page, on the .NET WebAssembly runtime. Nothing you write is ever run on the server - which is also why a program here cannot open a file or a socket, having neither a filesystem nor a network underneath it.

What you can call

A small fixed set of .NET reference assemblies, not the whole framework: the console, collections, LINQ, regular expressions, tasks and spans, plus the ghūl runtime. Anything outside that set will not compile, so this is a narrower .NET than a real project has.

Nothing here is saved, and reloading starts again from the example. The service is small and shared, so it can ask you to wait a moment.

Keeping what you write

ghul-scratchpad opens in a GitHub Codespace with the compiler already set up: paste something from here and carry on, with nothing to install.

For a real project, start from ghul-repository-template, which has the build, tests and CI wired up already - and the whole framework rather than the subset above.
